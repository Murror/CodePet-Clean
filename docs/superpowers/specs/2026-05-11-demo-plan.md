# CodePet — Demo plan (function chính)

**Date:** 2026-05-11
**Goal:** Demo Mirror layer — biến phiên làm việc thực với Claude Code
thành chương truyện do pet narrate. ~5 phút end-to-end, đủ để boss /
khán giả thấy được full loop.

---

## 0. State trước demo

- Đã clear: `events.jsonl`, `narratives.jsonl`, `session_summaries.jsonl`,
  `session_chats.json`. Backup ở `.bak-*` cùng folder.
- Hooks Claude Code: đã cài (xem `scripts/install-reflection-hooks.sh`).
- Pet đang chọn: ai cũng được. Demo dễ nói nếu là **Crash** (backend) hoặc
  **Nova** (frontend) — pet có persona rõ.
- Đăng nhập: signed-in (KHÔNG guest) để cloud function nhận được token.
- Network: ổn định (cloud function ở us-central1 + Anthropic call).

## Chạy thử trước demo (5 phút trước)

1. Mở app → đảm bảo Reflection tab chỉ có **Welcome** (chưa có session).
2. Mở terminal → `claude` → gõ 1 prompt nhỏ vd `ls -la` → đợi turn end.
3. Sang Reflection trong CodePet → kiểm tra: turn mới xuất hiện, sau ~5–10s
   pet narrate ra title + "what you wanted" + "what happened" + lesson.
4. Nếu thấy turn → demo sẵn sàng. Nếu không → check console logs cho
   `[NarrativeEnricher]`.

## Kịch bản 5 phút

### Phút 0 — Hook (30s)

> "Bạn đang code với Claude Code / Cursor. Cuối ngày bạn nhớ đã làm gì
> không? Bạn HỌC gì từ phiên đó không? AI nhớ thay bạn nhưng bạn thì
> không. CodePet đứng giữa khoảng trống đó."

Mở app: Dashboard / Reflection tab. Cho thấy app DESIGN giống game pixel.

### Phút 1 — Welcome state (30s)

Mở Reflection → Welcome card "Hi, I'm Crash 👋" trắng tinh.

> "App mới, chưa có session. 3 bước cài hooks → Claude Code bắt đầu nói
> chuyện với CodePet."

Click step 1 → highlight bash command. Skip nói chi tiết kỹ thuật.

### Phút 2 — Live capture (2 phút) — **trái tim demo**

Đặt cửa sổ Claude Code bên cạnh app. Gõ ngay trước mặt khán giả:

```
giúp tôi viết function tính fibonacci đệ quy bằng Swift
```

Claude Code làm việc → bạn switch sang CodePet. **Đợi 5–10s** — pet
narrate ra:

> "**Recursive fibonacci in Swift** — Bạn đã muốn hiểu sâu cách đệ quy
> hoạt động trong Swift. Mình thấy bạn đã viết function gọi lại chính
> nó, giải case lớn bằng case nhỏ hơn. Bài học: đệ quy đẹp khi base case
> rõ, nhưng tốn stack khi input lớn."

Đây là moment "wow". Nhấn mạnh:
1. Pet narrate bằng GIỌNG của Crash (backend), không phải robot
2. KHÔNG nhắc tới Claude / AI / model — pet là single voice
3. Lesson là **specific to this turn**, không phải fortune cookie

Gõ thêm 1 prompt nữa để có 2 turn:

```
viết test cho function vừa làm
```

→ Pet narrate turn thứ 2.

### Phút 3 — Session summary (1 phút)

Cuối phiên Claude Code → app phát hiện session ended → cho thấy nút
**"Summarize now"** ở đỉnh.

Click → ~5s sau, **Session Recap** xuất hiện:

> "Hai turn liền nhau, một dạy đệ quy, một viết test đảm bảo nó đúng.
> Bạn đi từ ý tưởng đến verify trong một mạch. Lesson: viết code và viết
> test sát nhau giữ cho ý tưởng còn tươi."

Đây là **arc-level lesson**, khác với per-turn lesson.

### Phút 4 — Chat với pet (1 phút)

Click bubble chat ở góc dưới-phải → side panel mở.

Hỏi pet:
```
Tại sao đệ quy hay bị stack overflow?
```

Pet trả lời theo giọng Crash, có context của session vừa rồi (đã biết
user vừa viết fibonacci đệ quy). Streaming live, có chấm tròn "is typing..."

Nhấn mạnh: **Pet có context của VIỆC vừa làm**, không phải chatbot
chung chung.

### Phút 5 — Dictionary + Profile (30s) — "wrap"

Quick switch:
1. **Dictionary tab** → "Recursion" → mở deep dive → analogy + code +
   when-to-use. Liên kết kiến thức kỹ thuật với việc vừa làm.
2. **Profile** → cho thấy pet đang chọn, sign-in status, có thể đổi
   pet để giọng narrate khác.

> "Pet bạn chọn quyết định giọng — Crash thẳng thắn, Nova chi tiết, Sage
> kiên nhẫn. Cùng phiên, 7 cách kể khác nhau."

## Các điểm cần highlight

| Điểm | Vì sao boss cần nghe |
|---|---|
| **Single voice narrator** | Không phải chatbot — là **nhân vật có ký ức**. Đây là moat. |
| **No-jargon translation** | Pet không nói "Edit file.swift" — nói "you tweaked the layout". Hợp với newbie nhưng vẫn educational. |
| **Per-turn AUTO + per-session MANUAL** | Auto-fire turn narrative khi turn end. Session summary chỉ chạy khi user opt-in. Tiết kiệm AI cost. |
| **Pixel-art design system** | Đồng bộ với pet sprites. Boss thấy app có identity riêng. |
| **Chat có context** | Pet đã đọc session, trả lời có hiểu. Không phải ChatGPT empty. |

## Rủi ro khi demo

| Vấn đề | Mitigation |
|---|---|
| Cloud function cold start 10–30s khi turn đầu | Đã set `minInstances:1` (nếu đã deploy). Pre-warm trước demo 5 phút. |
| Network gián đoạn | Có sẵn 1 narrative cũ trong bản backup → restore nhanh để show "đã work trước". |
| Pet narrate ra tiếng Anh khi user expect Vietnamese | Mặc định language = `vi` nếu locale là VN. Confirm `Locale.current.identifier` trước. |
| Hooks chưa cài / Claude Code log không tới | Test pre-demo (xem mục 0). Nếu hỏng → demo từ backup data restore. |
